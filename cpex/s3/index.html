02
Tablas y formato de datosTexto, fechas, moneda, bordes y alineación
⌄

El formato no cambia el valor del dato; cambia su presentación. En una planificación conviene usar fechas legibles, costos con formato moneda, encabezados destacados y bordes consistentes.

  • Texto: nombres y descripciones.
  • Fecha: permite ordenar y comparar cronogramas.
  • Moneda: hace evidente que el valor representa un costo.
  • Bordes y alineación: mejoran legibilidad y estructura visual.
03
Operadores y referencias de celdasAutomatización básica de cálculos
⌄

Excel calcula usando referencias como C2, E8 o rangos como E3:E8. Una fórmula siempre inicia con el signo =.

=E3+E4Suma dos costos
=E3-E4Calcula una diferencia
=E3*1.18Multiplica por un factor
=E3/2Divide un valor
04
Funciones esencialesSUMA, PROMEDIO, MAX, MIN, CONTAR y CONTARA
⌄
SUMA=SUMA(E3:E8)Totaliza los costos.
PROMEDIO=PROMEDIO(E3:E8)Obtiene el costo medio.
MAX / MIN=MAX(E3:E8)Identifica mayor y menor gasto.
CONTAR / CONTARA=CONTAR(E3:E8)Cuenta números o celdas no vacías.
05
Funciones condicionales y presupuestoCONTAR.SI, SUMAR.SI y SUMAR.SI.CONJUNTO
⌄

Las funciones condicionales responden preguntas específicas del presupuesto a partir de uno o varios criterios.

fx
CONTAR.SI=CONTAR.SI(B2:B15;"Marketing")Cuenta cuántos registros cumplen un criterio.
fx
SUMAR.SI=SUMAR.SI(B2:B15;"Catering";E2:E15)Suma los costos asociados a un criterio.
fx
SUMAR.SI.CONJUNTO=SUMAR.SI.CONJUNTO(E2:E15;B2:B15;"Marketing";D2:D15;"Pagado")Suma solo cuando se cumplen varios criterios.
Interpretar es parte del trabajo: el mayor gasto, el menor gasto y el promedio ayudan a comparar alternativas y sustentar decisiones básicas.
